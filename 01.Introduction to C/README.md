### 01. Introduction to C

In this directory, I practice various topics from my university slides and lectures. My goal is to preserve what I learn at university and build a strong foundation in C programming as a beginner.

The topics covered in this directory include:

* **a. Basic syntax of the C programming language**
* **b. Basic program structure**
* **c. Writing simple C programs**
* **d. Commonly used functions**, such as `printf()` and `scanf()`
* **e. Output formatting**, including:

  * Creating a new line using `\n`
  * Creating a horizontal tab using `\t`
  * Printing a backslash using `\\`
  * Printing double quotation marks using `\"`
* **f. Code readability techniques**, including:

  * Single-line comments using `//`
  * Multi-line comments using `/* ... */`

> **Learning Note:**
> These programs are based on my university learning materials and are written as part of my journey to understand C programming from the basics.
