### 02. Variables and Data Types in C

In this directory, I practice various topics related to variables and data types from my university slides and lectures. My goal is to strengthen my understanding of how data is stored, represented, and manipulated in C programming as a beginner.

The topics covered in this directory include:

* **a. Different data types in C**
* **b. Finding the size of different data types using the `sizeof` operator**
* **c. Understanding and using various format specifiers**
* **d. Commonly used functions**, such as `printf()` and `scanf()`
* **e. Type conversion**, including:

  * Implicit type conversion
  * Explicit type conversion (type casting)
* **f. Printing values without using variables**
* **g. Updating and modifying variable values**
* **h. Working with constant variables using `const`**
* **i. Swapping the values of two variables**

> **Learning Note:**
> These programs are based on my university learning materials and are written as part of my journey to understand variables, data types, and basic data manipulation in C programming.
